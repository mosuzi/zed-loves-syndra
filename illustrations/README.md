# 《影蚀天穹》插画包

本目录依据 `F:/mosuzi/zed-loves-syndra/content/chapters/` 的分章正文制作，未修改正文项目。

## 内容

- `插画制作清单.md`：人物连续性锁、世界风格、十五幅关键场景与正式封面的布景、机位、动作、光线、叙事禁区和统一提示词骨架。
- `00-视觉基准/`：主角设定板、配角群像设定板、世界与重点场景设定板，共 3 张。
- `01-关键场景插画/`：按 S01—S15 排列的最终插画，共 15 张，全部为 1672×941 PNG。
- `02-备选稿/`：未进入最终序列的修订前版本。
- `03-封面/`：正式竖版封面，1024×1536 PNG；保留正文仓库的 `public/og.png` 作为独立的横版社交分享图。

## 使用规则

后续补画时，至少同时引用 `B01-辛德拉与劫-人物基准.png` 与 `B03-世界与场景基准.png`；出现配角时再引用 `B02-配角群像-人物基准.png`。人物脸型、发型、服装轮廓、武器、法球、身高关系和场景结构均视为已锁定。

网页章节图建议保持 16:9 原图，不裁掉人物之间的距离、门槛、未使用的影路等叙事性留白。
